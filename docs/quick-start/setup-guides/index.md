## Cloud Options

If a 24 GB GPU is not available locally, rent one. The guide selects the cheapest practical instance per provider and covers provisioning and the provider-specific port-mapping requirements.

| Provider | Cheapest 24 GB GPU |
|---|---|
| **AWS** | NVIDIA L4 (`g6.8xlarge`) |
| **GCP** | NVIDIA L4 (`n4-highmem-16`) |
| **RunPod** | RTX 4090 |
| **Vast.ai** | RTX 4090 |
| **Tensordock** | RTX 4090 |
| **Lambda Labs** | A10 |
